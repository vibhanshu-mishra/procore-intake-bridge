# Cloud secret provider examples

These files contain placeholder references only. They do not select a provider, enable network
access, resolve a value, or prove production readiness.

Use `env` or `file` first. Cloud providers are optional for privately operated Sandbox or Pilot
environments, disabled by default, and require optional SDK installation plus explicit gates.

Never replace these examples with credentials, resource identifiers, URLs, account details,
project details, or local credential paths.
