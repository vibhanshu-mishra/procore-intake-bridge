# Example maintainer review checklist

- [ ] Confirm `0.1.0` is prepared metadata, not a release.
- [ ] Run `COMMAND_PLACEHOLDER` and inspect only sanitized local output.
- [ ] Confirm no release, build, tag, publish, upload, or deployment occurred.
- [ ] Review `HANDOFF_DOMAIN_PLACEHOLDER` and `KNOWN_LIMITATION_PLACEHOLDER`.
- [ ] Obtain private security/privacy/legal/infrastructure review at
      `PRIVATE_REVIEW_REF_PLACEHOLDER`.
- [ ] Record `REVIEW_DECISION_PLACEHOLDER` outside Git.

This example grants no production, Pilot, release, deployment, Procore, publication,
certification, or compliance approval.
