# Example maintainer command plan

| Order | Command | Boundary |
|---:|---|---|
| 1 | `COMMAND_PLACEHOLDER` | Offline and non-writing |
| 2 | `make maintainer-handoff` | Sanitized local report only |
| 3 | `make maintainer-review-checklist` | Checklist only; no approval |
| 4 | `make maintainer-decision-log-template` | Placeholder template only |

No command in this example builds, publishes, tags, releases, deploys, or contacts an external
service. Maintainer review and private review remain required.
