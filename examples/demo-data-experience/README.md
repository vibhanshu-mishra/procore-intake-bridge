# Demo data experience examples

These files illustrate the J2 document shapes with placeholders and fake values only. They are
not generated reports and contain no customer data, identities, domains, URLs, IDs, private paths,
credentials, logs, database dumps, attachment contents, approvals, or private report contents.

- `example_demo_seed_plan.md` shows a placeholder seed plan.
- `example_demo_reset_plan.md` shows a non-destructive placeholder reset plan.
- `example_demo_data_inventory.csv` shows a formula-safe placeholder inventory.

Real generated output belongs in ignored local demo-output roots. J2 uses deterministic fake data
and local SQLite only; it performs no Procore, cloud, or external-database call.
