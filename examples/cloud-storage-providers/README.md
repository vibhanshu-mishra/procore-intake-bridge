# Cloud storage provider examples

These examples contain placeholder references only. They select no provider, enable no network
access, perform no object operation, and contain no object contents.

Use local storage first. S3, Azure Blob, and GCS are optional for privately operated Sandbox or
Pilot environments and require an optional SDK plus explicit gates. List, delete, and overwrite
remain separately disabled. G2 provides no presigned URLs.

Never replace these placeholders with credentials, provider resource identifiers, bucket or
container names, project/account details, object keys from live data, URLs, or file contents.
