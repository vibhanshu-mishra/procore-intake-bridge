# Example pre-tag reminder checklist

Future manual review reminder only. It does not perform a tag or release. No release, build,
publish, upload, deploy, issue filing, ticket creation, or approval is represented.

- [ ] Confirm `MAINTAINER_DECISION_PLACEHOLDER` and staged files agree.
- [ ] Review `KNOWN_LIMITATION_PLACEHOLDER` and `PRIVATE_REVIEW_REF_PLACEHOLDER`.
- [ ] Run local safety and documentation checks; keep generated output temporary.
- [ ] Remove private values, reports, paths, and customer identifiers.
- [ ] Record `PRE_TAG_REMINDER_PLACEHOLDER` outside Git.

After a future human-approved release, use the post-release roadmap as a separate planning aid.
