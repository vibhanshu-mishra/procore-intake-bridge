# Post-release roadmap examples

These placeholder-only examples show the shape of the J10 planning pack. “Post-release” means
after a future human-approved `0.1.0` release; no release happened in J10. The examples do not
build, publish, upload, tag, deploy, open issues, create tickets, or grant approval.

Keep real evidence, identities, credentials, domains, customer data, reports, logs, and approval
records in a private review system. Replace placeholders only in that private context.

- `example_post_release_roadmap.md` — candidate horizons and dependencies.
- `example_known_limitations_register.md` — sanitized limitation rows.
- `example_future_work_backlog.md` — uncommitted candidate work.
- `example_private_review_backlog.md` — private gate references.
- `example_pre_tag_reminder_checklist.md` — future manual review reminders.
- `example_post_release_roadmap_matrix.csv` — compact, placeholder-only matrix shape.
