# Infrastructure Security Checklist

- [ ] Keep secret and database configuration reference-only.
- [ ] Keep storage review metadata-only and exclude keys, presigned URLs, and contents.
- [ ] Keep external providers and database operations separately gated.
- [ ] Keep diagnostics masked and generated outputs ignored.
- [ ] Complete private provider-permission, resource-policy, role, network, and operational review.
- [ ] Do not claim certification or production, launch, or pilot approval.
