# Data Retention Map

The I4 retention map covers the public repository, local demo SQLite data, planned PostgreSQL runtime, webhook queue, attachment manifest metadata, lifecycle history, operator exports, diagnostics, support bundles, sandbox and pilot evidence references, generated output, private workspaces, and cloud-provider reference boundaries.

It is an offline documentation map. It performs no live scan, deletion, purge job, database connection, or external call. Specific retention periods and legal requirements remain private-review decisions.

Run `make data-retention-map` to print the sanitized map.
