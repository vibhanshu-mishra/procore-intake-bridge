# Final readiness checklist

- [ ] Run `make quality`.
- [ ] Run `make safety-check`.
- [ ] Run `make docs-site-check`.
- [ ] Run `make release-readiness`.
- [ ] Run `make final-readiness`.
- [ ] Review public examples, fixtures, documentation navigation, and known limitations.
- [ ] Confirm live-gated commands remain outside default and quality targets.
- [ ] Confirm generated outputs and private workspaces remain ignored.
- [ ] Confirm private values and real reports stay outside Git.
- [ ] Decide any future release, production, or pilot action separately.

This checklist is a maintainer-review aid. It is not release approval, not production approval,
and not pilot approval. No live operations happen.
