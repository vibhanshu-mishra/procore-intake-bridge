# Minimum permissions checklist

- RFIs: **Read Only**
- Submittals: **Read Only**
- Attachments: only those visible through permitted RFIs/Submittals
- Project metadata: Read Only, and only if required for identification
- Projects: explicitly allowlisted per connection
- Write permissions: **none requested**

Do not grant create, update, delete, approve, submit, close, upload, or administrative permissions.
Recheck access after app version, DMSA, company, or project membership changes.
